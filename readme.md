⚒️ The Hardware

## Networking
As a [Ubiquiti](https://www.ui.com) fanboy, of course my network is headed by a [Dream Machine Special Edition](https://store.ui.com/us/en/collections/unifi-dream-machine/products/udm-se). Add to that a couple of [U6 Pros](https://store.ui.com/us/en/collections/unifi-wifi-flagship-high-capacity/products/u6-pro) and a scattering of [Switch 8 PoE (60W)s](https://store.ui.com/us/en/products/us-8-60w) for some ethernet goodness and you've got from my experience a rock-solid prosumer network.

## Compute
Initially I picked up a couple of second hand [Dell Optiplex 7070 Micro](https://www.dell.com/support/manuals/en-au/optiplex-7070-micro/opti7070_micro_setup_specs/system-specifications) PCs to use as [Proxmox](https://www.proxmox.com) hosts. These worked really well as a starting off point for a proof of concept, but were a little underpowered for my desires.

More recently I have upgraded those to three [MINISFORUM MS-01 Workstation](https://store.minisforum.com/products/minisforum-ms-01?variant=46713695011061) Mini PCs. These are barebones systems that ship with only an [Intel i9 13900H](https://www.intel.com/content/www/us/en/products/sku/232135/intel-core-i913900h-processor-24m-cache-up-to-5-40-ghz/specifications.html) inside. I picked up a [96GB DDR5 Crucial Memory Kit](https://www.crucial.com/memory/ddr5/ct2k48g56c46s5) and a [2TB Samsung 990 PRO](https://www.samsung.com/au/memory-storage/nvme-ssd/990-pro-2tb-nvme-pcie-gen-4-mz-v9p2t0bw/) for each of them to put together some pretty kick-ass little boxes. Let's see if these last me any longer than the previous iteration...

## Storage
This part is still somewhat in limbo.

Previously I was waiting for the [Ubiquiti NAS](https://ui.com/integrations/network-storage) to release. It's since released, but they seem to be having some drive incompatibility issues so I'm going to wait for the 8-bay variant to start shipping and see how they're tracking then.

In the meantime, I'll continue to play with [TrueNAS Scale](https://www.truenas.com/truenas-scale) and a [Seagate IronWolf Pro 8TB](https://www.seagate.com/au/en/products/nas-drives/ironwolf-pro-hard-drive) in a [Orico 3.5in External Hard Drive Enclosure](https://www.orico.cc/usmobile/product/detail/id/3518). This should tide me over for a little while longer (along with the 6TB of storage pooled from the servers themselves).
